# Order Management Microservices

## Overview
Microservices-based order management application built using Java 17
and Spring Boot.

## Architecture
- API Gateway
- Order Service
- Product Service
- Notification Service

## Technologies
- Java 17
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Apache Kafka
- Redis
- Spring Security
- JWT
- Docker
- AWS

## Features
- User authentication and authorization
- Product management
- Order management
- Event-driven notifications
- Redis caching
- REST APIs
